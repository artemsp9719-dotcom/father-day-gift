# С Днём отца!

Личный сайт-подарок от Артема. При прокрутке две бархатные шторы плавно расходятся в стороны, открывая праздничную сцену. Сначала загораются гирлянды, затем тёплый прожектор освещает танцующего 3D-персонажа. При переходе к поздравлению свет следует за ним. Затем появляются пожелание и подпись.

## Открыть сайт

Дважды нажми `Открыть сайт.cmd`. Откроется браузер и окно локального сервера. Пока смотришь сайт, оставь окно сервера открытым. Для остановки нажми в нём Ctrl+C.

Или из этой папки:

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

Открой http://127.0.0.1:4173/. Для прокрутки работают колёсико, тачпад, свайп, стрелки, Page Down и пробел; Home возвращает к началу. Если в системе включено уменьшение движения, персонаж замирает, а шторы следуют за прокруткой без сглаживания. При прокрутке обратно шторы снова закрываются.

## Поставить свою 3D-модель

Сейчас подключена твоя модель из `dancedad.fbx`: `public/models/dad-hunyuan-dance.glb`. Сохранены текстура, скелет и танец длительностью 4,15 секунды, который повторяется по кругу. Исходные `dancedad.fbx`, `dadrigged.fbx` и тестовый `public/models/dad.glb` сохранены. Размер рабочего GLB — около 32 МБ; на медленном интернете первая загрузка может занять время.

При следующей замене укажи путь нового GLB в `public/model-config.json`, либо замени файл по уже указанному там пути.

1. Экспортируй персонажа из 3D-программы в **glTF Binary (.glb)**. Включи материалы, текстуры и анимацию в экспорт. В Blender формат называется **glTF 2.0**, тип **glTF Binary**. Пока используй обычный экспорт без Draco-сжатия.
2. Замени тестовый файл `public/models/dad.glb` своим файлом с таким же именем. Перед заменой сохрани копию тестового файла, если хочешь оставить его.
3. Перезагрузи страницу. Размер и положение по высоте подстроятся автоматически. Код менять не нужно.

Дополнительные настройки находятся в `public/model-config.json`:

```json
{
  "modelUrl": "/models/dad.glb",
  "animationName": null,
  "rotationY": 0,
  "height": 3.6
}
```

- `animationName`: название танцевальной анимации; `null` включает первую анимацию из файла.
- `rotationY`: поворот в радианах. Если модель стоит спиной, попробуй `3.14159`.
- `height`: высота модели на сцене. Обычно менять не нужно.
- `maxHipLean`: ограничение наклона таза в радианах для анимаций со слишком сильным заваливанием. Для текущего танца задано 15° (`0.2617993878`); поворот вокруг вертикальной оси и движения конечностей сохранены. При замене модели параметр можно убрать.
- `smoothDance`: включает сглаживание ключей танца и плавный переход к началу. Для текущей модели включено; цикл с переходом длится около 4,77 секунды.
- Без анимации модель слегка покачивается целиком. Для движения рук и ног нужно экспортировать танец вместе с персонажем.
- Если файл не загрузился, остаётся тестовый персонаж. Вернуть его вручную: поставь `modelUrl` обратно в `null`.

Текущий `dad.glb` содержит настоящую анимацию `DadDance` (петля примерно 3,3 секунды). Скрипт `node scripts/export-demo.mjs` заново создаёт тестовый файл и перезаписывает `public/models/dad.glb`: не запускай его после замены файла своей моделью, если не сохранил её отдельно.

Если захочешь повторить тестовый танец на своей модели, удобнее передать готовый `.glb` с анимацией. Скелеты разных персонажей не всегда совместимы автоматически.

## Где что находится

- `src/App.jsx` — все согласованные надписи и структура страницы.
- `src/styles.css` — внешний вид и адаптация для телефона.
- `src/story.js` — последовательность появления элементов.
- `src/dad.js` — тестовый объёмный персонаж и танец.
- `src/stage.js` — свет, камера, отрисовка и загрузка своей модели.
- `src/lighting.js` — гирлянды, объёмный луч и прожектор, следующий за персонажем.
- `public/assets/` — праздничная сцена, текстура бархатных штор и запасное статичное изображение. Старые изображения гаража сохранены, но сайт их не использует.
- `public/model-config.json` — настройки твоей модели.
- `reference/approved-concept.png` — первоначальный эскиз расположения надписей. Фон и занавес изменены по твоему уточнению от 18.10.2026.
- `design-qa.md` — результат визуальной проверки.

Музыка и кнопки не добавлены. Шрифты и изображения лежат локально; сайт не обращается к внешним CDN и не собирает данные.

## Сборка

```sh
npm run build
```

Готовые файлы сайта находятся в `dist/client`. Эта папка подходит для обычного статического хостинга. Открывать HTML двойным нажатием не нужно: 3D-модель и модули загружаются через HTTP. Для просмотра сборки можно использовать `npm run preview -- --host 127.0.0.1 --port 4174`.

Публикация ещё не выполнена: локальная ссылка работает только на этом компьютере. После добавления твоей модели можно сделать публичную ссылку для папы.

Фоны и запасное изображение созданы ImageGen для этого проекта. Шрифты Oswald, Manrope и Caveat распространяются по SIL Open Font License; файлы лицензий находятся в `licenses/`. Three.js — MIT.
